## 🤝 How to contribute

- **Found a mistake?** [Report it with the form](https://github.com/Dazy80/Anki-Decks-Community-Feedback-Contributions/issues/new/choose). The number after **Freq.n:** on the card and the German word are enough – one report can list many notes.
- **Want to correct it yourself?** All notes are in CSV files, one row per note. Edit them right here on GitHub and send a pull request – an automatic check helps you. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **Questions or bigger ideas?** Start a [Discussion](https://github.com/Dazy80/Anki-Decks-Community-Feedback-Contributions/discussions).

Accepted corrections go into the next version of the deck on AnkiWeb.
